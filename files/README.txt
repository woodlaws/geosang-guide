files 폴더 — 자료실에서 내려받는 양식 파일을 넣는 곳입니다.

[넣는 방법]
1. 양식 파일을 이 폴더에 넣습니다.
2. data/library.js 파일을 열어 해당 항목의 file 이름을 파일명과 똑같이 맞춥니다.
3. 같은 항목의 ready 를 false 에서 true 로 바꿉니다.
   -> 자료실의 "준비 중" 버튼이 "받기" 버튼으로 바뀌고 다운로드가 됩니다.
