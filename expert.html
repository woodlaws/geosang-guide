이럴 때는 전문가가 필요합니다

연결 요청을 남겨 주시면 해당 분야 전문가와 연결해 드립니다.

  • 세무사

    이럴 때 필요합니다

    • 부가세 · 종합소득세 신고를 직접 하기 어려우실 때
    • 세금계산서와 증빙 처리 기준이 헷갈리실 때
    • 세액감면 대상인지 확인하고 싶으실 때
    연결 요청

  • 회계사

    이럴 때 필요합니다

    • 재무제표와 회계 기준을 정리해야 하실 때
    • 투자 유치나 정책자금용 재무 자료가 필요하실 때
    • 내부 관리 체계를 갖춰야 하실 때
    연결 요청

  • 변리사

    이럴 때 필요합니다

    • 상표를 출원해 상호를 지키고 싶으실 때
    • 제품이나 기술을 특허로 보호하고 싶으실 때
    • 이미 등록된 권리와 겹치는지 확인하실 때
    연결 요청

  • 변호사

    이럴 때 필요합니다

    • 계약 내용을 두고 분쟁이 생겼을 때
    • 임대차 · 권리금 문제로 다툼이 있을 때
    • 내용증명 발송이나 소송 대응이 필요하실 때
    연결 요청

  • 법무사

    이럴 때 필요합니다

    • 법인 설립 등기를 해야 하실 때
    • 주소 · 임원 · 자본금 등 등기 사항이 바뀌었을 때
    • 부동산 등기나 근저당 업무가 필요하실 때
    연결 요청

  • 행정사

    이럴 때 필요합니다

    • 인허가 신청 서류 작성이 막히실 때
    • 관공서에 낼 서류를 대신 준비해야 하실 때
    • 행정 처분에 이의를 제기하셔야 할 때
    연결 요청

  • 노무사

    이럴 때 필요합니다

    • 첫 직원을 채용해 근로계약과 4대보험을 정리하실 때
    • 임금과 근로시간 기준이 맞는지 확인하실 때
    • 고용 장려금 신청 요건을 확인하실 때
    연결 요청

  • 관세사

    이럴 때 필요합니다

    • 해외에서 물건을 수입하실 때
    • 제품을 수출하며 통관과 관세를 확인하실 때
    • FTA 원산지 증명이 필요하실 때
    연결 요청

전문가 상담 비용과 진행 방식은 분야와 사안에 따라 다릅니다. 연결 요청을 주시면 먼저 안내해 드린 뒤 진행합니다.
