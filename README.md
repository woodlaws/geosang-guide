# 거상 창업내비

퇴사 준비부터 재도전까지, 창업 7단계마다 무엇을 해야 하는지 안내하는 홈페이지입니다.

설치할 프로그램 없이 **HTML · CSS · JavaScript 파일만으로** 만들어져 있습니다.
`index.html` 을 더블클릭하시면 바로 열립니다.

---

## 내용을 고치고 싶을 때

거의 모든 글은 `data` 폴더의 파일 네 개에 들어 있습니다. **이 파일만 고치시면 홈페이지 전체가 함께 바뀝니다.**

| 파일 | 고치면 바뀌는 곳 |
| --- | --- |
| `data/stages.js` | 창업 7단계의 단계명 · 해야 할 일 · 필요 서류 · 지원사업 (단계 페이지, 메인 카드, 시나리오 타임라인이 모두 이 파일을 씁니다) |
| `data/support.js` | 지원사업 찾기 페이지의 카드 목록, 카드에 표시되는 기준 연도(`basisYear`) |
| `data/library.js` | 서식 자료실의 양식 목록 |
| `data/check.js` | 3분 창업 진단의 문항과 주의 문구 |

`[대괄호]`로 표시된 곳은 아직 확인되지 않은 내용입니다. 확인되는 대로 채워 주십시오.

## 양식 파일을 올리고 싶을 때

1. 양식 파일을 `files` 폴더에 넣습니다.
2. `data/library.js` 에서 해당 항목의 `file` 이름을 실제 파일명과 맞춥니다.
3. 같은 항목의 `ready` 를 `false` 에서 `true` 로 바꿉니다.

→ 자료실의 "준비 중" 버튼이 "받기" 버튼으로 바뀝니다.

## 공유 이미지

카카오톡이나 페이스북에 링크를 붙였을 때 보이는 이미지입니다.
`images/og-cover.png` 자리에 **가로 1200 × 세로 630** 크기의 이미지를 넣어 주십시오.

## 신청 정보가 저장되는 곳

자료실 양식 받기, 진단 결과지 받기, 상담 신청 내용은 Supabase 프로젝트 **geosang-navi** (서울 리전)에 저장됩니다.

- `leads` 표 — 자료실 · 진단 결과지 신청자
- `consultations` 표 — 상담 신청

supabase.com 에 로그인하신 뒤 해당 프로젝트의 **Table Editor** 에서 확인하실 수 있습니다.
홈페이지에 들어 있는 키는 **입력 전용 공개 키**이며, 그 키로는 저장된 내용을 읽을 수 없도록 막아 두었습니다.

## 폴더 구조

```
index.html                    메인
stage-0.html ~ stage-6.html   창업 7단계 상세
support.html                  지원사업 찾기
library.html                  서식 자료실
check.html                    3분 창업 진단
scenario-youth.html           청년 창업 시나리오
scenario-senior.html          은퇴 · 경단 창업 시나리오
expert.html                   분야별 전문가
contact.html                  무료 상담 신청
css/style.css                 전체 공통 디자인
js/                           기능
data/                         내용 (여기를 고치십시오)
files/                        내려받는 양식 파일
images/                       로고 · 사진 · 공유 이미지
```
